# 两分钟讲稿

各位老师、同学，大家好。第24组由徐阳、廖信同、黎欣欣、周艳雯、殷浚峰共同完成，我们汇报的题目是《面向校园多跳问答的知识图谱混合搜索：GA-A*、MCTS与受约束LLM辅助》。

我们的任务，是让人物、社团、活动和地点之间的多跳关系变得可搜索、可核验。知识图谱包含504个实体、1234条三元组，核心问题662道，稳健问题112道，问题限定为2到4跳。正式测试抽取160道题，五种搜索方法共形成800条记录。

搜索层比较了广度优先、手工A*、遗传算法优化的A*、蒙特卡洛树搜索，以及路径价值分类器增强的A*。所有方法共享同一公开图结构、问题集合和预算。GA-A*平均扩展3.59375个节点、检查5.2125个候选，比广度优先减少约28.39%的扩展和38.36%的候选检查。MCTS平均只扩展1.83125个树节点，但它还要执行随机rollout，所以不能只看这个数字。分类器把扩展节点进一步降到3.2，却把候选检查提高到7.21875，速度与覆盖之间存在交换。

五种方法的答案准确率和路径有效率都达到1.0。107道可解题全部返回至少一条标准路径，53道无解题全部返回空集。严格路径完整率只有0.13125，这是补充指标。每种方法有21题返回全部标准路径，86题只返回非空真子集；另外53道无解题的空集回答在主指标中正确，却因当前完整率实现要求预测路径非空而被计为不完整。因此，主指标说明问答可用，完整率提醒我们：要求列出全部证据路径时，还需要调整停止条件和枚举预算。

LLM部分采用严格约束。模型只能评价给定候选，或解释已经验证的路径；动作是否合法、路径奖励是多少、证据能否引用，全部由本地代码决定。51项相关单元测试已经通过，官方DeepSeek也完成了真实评分和解释验证；但正式实验没有把LLM评分混入算法对照，所以目前不宣称获得了稳定LLM收益。

下一步，我们会完善多路径枚举、重复计时与置信区间，并完成真实LLM对照实验。谢谢大家。
