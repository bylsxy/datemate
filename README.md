# DateMate · 约会策划

[在线使用](https://bylsxy.github.io/datemate/)。

首页呈现条件、探索度、场景时间与地点活动卡。地点卡位置固定，点击立即高亮并平滑居中，边缘卡随滚动缩小；计算中的内容使用骨架屏，连续点击保留最新选择。卡片右上角显示0—100方案契合分，尚未评估完整后续时显示“待评估”。知识、对比、输入输出和版本信息通过右下角主题色圆形悬浮按钮向上展开的“三”菜单进入；输入输出页可复制当前条件及已计算方案。错误提示会自动滚入视野。

## 编辑知识库

当前管理电脑提供本地表单编辑器，双击 `知识库编辑器.cmd` 即可打开。选择场景、活动或规则，在表单里编辑后点击“保存全部”，程序会校验、备份并重建本地运行数据和离线版。编辑器和备份被 Git 忽略，线上更新由管理者自行提交并推送。

需要直接处理源文件时，也可采用下面的文本编辑方式。

编辑 `knowledge/scenes.json` 修改地点名称、卡片说明、固定分钟数和活动挂载；编辑 `knowledge/activities.json` 修改活动名称、费用、体力、准备和依赖；编辑 `knowledge/rules.json` 修改推理规则。它们都是UTF-8文本JSON，可以用VS Code或记事本打开。

保存后双击 `重建知识库.cmd`，或执行：

```bash
node tools/build_catalog.mjs
node tools/build_catalog.mjs --check
node tools/build_offline.mjs
```

编译会验证ID、挂载与依赖，再生成 `data/` 中的运行时知识图谱和规则，不覆盖你编辑的 `knowledge/`。自动修订指纹用于拒绝过期复盘。详细字段与例子见[编辑指南](docs/编辑知识库.md)。更新线上版本还需要提交并推送到GitHub。

## 时间与资源

当前知识包含86个地点、150个独立活动、175条挂载关系、4种分别方式、59条产生式规则。华农地点依据用户本地亲历描述登记，包含校内及周边的范围选项。全部151份本地语料登记保留，公开内容使用原创摘要与设计参数。

条件支持关系阶段、小别重逢、心情、精力、假期与临考、庆祝场合、中日式主题、双方兴趣及16型人格。天气默认阴天，晴天户外给出简短防晒提示；雨天、安静、人少、室内与脑力偏好调整排序。明确预算、忌口、排除项、可用时段和活动前置依赖继续参与可行性检查。周期状态只提供轻负荷、座位与正餐方面的温和参考；人格四维以低权重设计启发参与，不预测关系或亲密意愿。

探索度100进入梦幻模式，提供热气球、海岛、跨城演出等大型灵感；时间、交通和预算照常核算。自助餐等场景可分别登记周中与周末的双人设计费用。社交性按地点和具体玩法登记为0至3：二人独处、少量交流、团体互动、公开表达。知识图谱记录条件、活动依赖和设计属性；产生式规则包含长期关系求新、临考校园短会、重逢共同体验与周末人流等推理链，可在“知识与推理”查看。

可选时段为上午07:30—12:00、下午14:00—18:00、晚上19:00—23:00和夜晚23:00—次日02:00。连续多选会形成从首个时段开始到最后一个时段结束的完整时间窗，中午和傍晚间隔也可安排；非连续选择会提示“只能整段规划”。

包含上午时提供早餐地点和“会面前吃早餐”；跨上午、下午安排午餐，跨下午、晚上安排晚餐，跨晚上、夜晚在23点附近提供宵夜地点和“不吃宵夜”。这些选择位于规划区，用餐费用、体力和后续时间都参与计算。地点的餐次写在 `mealRoles`，实际餐食活动也有对应餐次，并提供 `meal_completed`。

末尾提供各自回去、一起走一段，以及跨午夜时可选的酒店和露营。分别方式的时间和费用先参与可行性检查，过夜由用户明确选择。高级选项默认一线城市；一线、二线、三线及以下的双人房一晚设计区间分别为200—400、150—300、100—250元，露营双人一晚设计区间为120—300元。实际报价、住宿与营地条件按所选日期确认。相关参数可编辑 `knowledge/departures.json`。

阶段时长按 `scene.minutes` 和 `durationRange` 安排，可在界面调整。所选活动共享该段时间，继续影响费用、体力、资源、互斥、准备和后续选择。自动排程考虑不同停留长度，并优先为结尾选择留出时间；临考单时段且无预约、必需饭点时允许短会后提前分别。转场、时间窗、结束缓冲与预约锚点仍参与约束。金额只在首页末尾显示建议余额。

求解采用确定性有界束搜索、透明效用与Pareto筛选。候选使用同阶段固定评分参考，已确认完整后续与尚未评估的候选分别呈现，未证明全局最优。场地和体验参数可按真实反馈在编辑源中调整。

## 本地验证

```bash
node --test tests/*.test.mjs
node tools/verify_reproducibility.mjs
python -m http.server 8837 --bind 127.0.0.1
```

访问 `http://127.0.0.1:8837/`，开发验收使用独立端口。原始语料抽取入口 `tools/build_knowledge.py` 默认拒绝覆盖编辑源，显式抽取只写候选临时目录。报告、PPT和录屏材料应在手工知识库定稿后同步。
